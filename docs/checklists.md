# Checklists

Printable checklists to keep you organized. Copy these into a notebook, notes app, or print them out.

## Documents checklist

Gather these before you start applications (check off each one you have):

- [ ] Photo ID (driver's license, state ID, passport)
- [ ] Social Security number or card
- [ ] Birth certificate(s) — for you and dependents
- [ ] Proof of income (pay stubs, employer letter, tax return, benefit letter)
- [ ] Proof of address (utility bill, lease, mail with your name and address)
- [ ] Bank statements (if required)
- [ ] Rent or mortgage documents (lease, receipts, statement)
- [ ] Utility bills (electric, gas, water, internet)
- [ ] Immigration documents (if applicable)
- [ ] Disability or medical records (if applying for disability-related programs)
- [ ] Other: ______________________________________
- [ ] Other: ______________________________________

## Program search checklist

- [ ] Make a list of the types of help you need (food, healthcare, housing, income, etc.)
- [ ] Search Benefits.gov for federal programs
- [ ] Search your state, county, or city government website
- [ ] Call 211 or visit 211.org for local resources
- [ ] Ask a librarian or community action agency for help
- [ ] Write down programs you might qualify for
- [ ] Save program phone numbers and websites
- [ ] Note application deadlines, if any

## Before you submit checklist

- [ ] Read the whole form first
- [ ] Fill in all sections (write "none" or "N/A" if a question doesn't apply)
- [ ] Check names, addresses, and Social Security numbers against your ID
- [ ] Attach or upload required documents (copies, not originals)
- [ ] Sign and date the form
- [ ] Save a copy of the completed application
- [ ] Save the confirmation number or screenshot
- [ ] Note the date you submitted

## After you submit checklist

- [ ] Write down the confirmation or reference number
- [ ] Note the expected decision date (if given)
- [ ] Save all emails, letters, and notices in one folder
- [ ] Set a reminder to check your status in 1–2 weeks
- [ ] Respond quickly to any requests for more information
- [ ] If denied, read the appeal instructions and note the deadline

## Weekly tracking habit

Pick a day and time (for example, Tuesday afternoons) and:

- [ ] Check application status online or by phone
- [ ] Update your tracking sheet
- [ ] Follow up on any pending requests
- [ ] Take a break and celebrate small steps

## Weekly tracking habit

You don't have to finish every checklist in one day. Do one item at a time, and it's okay to pause and come back later.
